ONVIF Configuration

ONVIF Profile & Protocol Settings

Configure ONVIF profile streaming, discovery, audio backchannel and NVR interoperability.

WS-Discovery Enable ONVIF automatic network discovery daemon.
Active Profiles Expose high resolution, low resolution, or both streams.
Snapshot Watermark Embed timestamp watermark directly onto ONVIF snapshots.
Audio Decoder (Backchannel) Two-way audio talkback codec used by ONVIF clients.
Media2 Support Enable ONVIF Media Service 2.0 configuration and streaming.
Fault Response Reply with standard SOAP fault if a request is unrecognized.
Synology Surveillance Station Apply protocol quirks for enhanced Synology NVR compatibility.
Note: Configuration changes take effect after camera reboot.
