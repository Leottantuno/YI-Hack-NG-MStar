Static IP Configuration

Network Interface (IPv4)

Configure a static IP address. If left blank, DHCP will be automatically used to acquire network parameters.
Warning: Entering an incorrect IP or gateway may cause loss of network access.

IP Address Camera static IP (e.g. 192.168.1.100)
Subnet Mask Network netmask (e.g. 255.255.255.0)
Gateway Default router IP address
Primary DNS Main DNS resolver (e.g. 1.1.1.1)
Secondary DNS Fallback DNS resolver (e.g. 8.8.8.8)
Note: Network changes require a reboot to take effect.
