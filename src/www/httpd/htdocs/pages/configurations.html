System Configurations

Configure network identification, core streaming daemons, cloud privacy, local snapshot options, system services and security credentials.

General & Streaming Settings
Hostname Camera network hostname. Leave blank for auto.
Timezone POSIX timezone string (Timezone list).
Disable Cloud Completely cut off Yi App cloud telemetry and services (pure private local mode).
Local SD Recording Without Cloud Preserve 24/7 video recording on microSD even with Cloud disabled.
RTSP Server Enable RTSP live video/audio streaming server.
RTSP Server Core Underlying streaming daemon engine.
RTSP Stream Resolution Resolution exposed to RTSP clients.
RTSP Audio Codec Audio stream format for RTSP clients.
Audio Noise Reduction Digital filter level for PCM/A-law/μ-law (0 to disable).
ONVIF Protocol Expose ONVIF profiles for NVR/VMS integration (Detailed ONVIF settings).
Time OSD Render timestamp overlay in upper left video corner.
Snapshots & Time-lapse
Snapshot HTTP Service Enable /cgi-bin/snapshot.sh endpoint.
Snapshot For Recorded Video Generate thumbnails for recordings (CPU expensive).
Force Low Res Snapshot Capture 360p snapshot to minimize RAM usage.
Time-lapse Feature Periodic frame capture (View clips).
Time-lapse Interval (min) Minutes: 1-6, 10, 15, 20, 30, 60, 120, 1440.
Video Compilation Cron Crontab expression (e.g. 0 0 * * *).
FTP Push Snapshots Push time-lapse frames to remote FTP and delete locally.
Overwrite Remote Frame Use identical filename when uploading via FTP.
Network & System Daemons
SSH Server (Dropbear) Secure remote shell access on port 22.
FTP Server (Pure-FTPd) High-performance FTP access on port 21.
Legacy BusyBox FTP Fallback lightweight BusyBox FTP daemon.
Telnet Server Insecure unencrypted shell access (not recommended).
NTP Daemon (Time Sync) Network time sync daemon (required if Cloud is disabled).
NTP Server Address
Web Server (HTTPD) Warning: Disabling will block this WebUI.
mDNS Daemon (Avahi) ZeroConf / .local domain resolution on LAN.
Proxychains-NG Bypass region restrictions via SOCKS/HTTP proxy.
Ports & Access Credentials
RTSP Port Default: 554
HTTPD Port Default: 80
Streaming / Web User Username for RTSP, ONVIF & WebUI.
Streaming / Web Password Password for RTSP, ONVIF & WebUI.
Root Shell Password System password for SSH, Telnet & FTP.
